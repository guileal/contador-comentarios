Instalar o contador

Arraste o botão para a barra de Favoritos. Depois, no post do Instagram, clique nele para abrir o placar.

  1. Se já existir um favorito Contar votos, apague-o
  2. Mostre a barra de Favoritos: Cmd + Shift + B
  3. Arraste o botão amarelo para essa barra (não clique nele aqui)
  4. Abra o post do Instagram no Safari, já logado
  5. Clique em Contar votos nos Favoritos
