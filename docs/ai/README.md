# Instruções para IAs

Este projeto conta votos por menção (`@`) em comentários de um post do Instagram. Há três superfícies: extensão Chromium, atalho de Favoritos no Safari e um CLI em Python.

Leia nesta ordem:

1. [architecture.md](architecture.md) — o que cada pasta faz e como os scripts se falam
2. [conventions.md](conventions.md) — regras de voto, textos e o que nunca entra no git
3. [workflows.md](workflows.md) — como alterar collector, overlay, extensão e CLI

`AGENTS.md` na raiz aponta para cá. Cursor também carrega `.cursor/rules/`.
